In the browser, not on a server

Contracts are confidential. Comparing them on your own computer means there is no upload to worry about, no copy kept anywhere, and nothing to delete afterwards.

No AI

A comparison should be exact and repeatable. redline follows fixed rules, so the same two documents always give the same redline, and nothing is guessed or summarised.

A checker that is separate from the redline maker

The part of redline that makes the redline does not get to mark its own work. A separate checker takes every file apart again and confirms it matches your documents, for example that removing the deleted text gives back the modified document exactly. A file is offered only when it passes.

Marks lawyers already know

The marks follow the conventions of established legal comparison tools, so a redline from redline reads like the ones lawyers already exchange.

Open source

Every rule above can be checked by reading the code. It is public on GitHub.
