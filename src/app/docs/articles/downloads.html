The formats

PDFpdf
The static redline as a PDF, ready to send. Best for sharing and printing.
DOCword · static redline
A Word file with the changes marked up as text, and no tracked changes. Good when you want to edit around the marks.
DOCword · tracked changes
A Word file where every change is a tracked change, so you can accept or reject each one in Word.

When a format is not offered

A format appears only when every check on that file has passed. If a check fails, the format is greyed out in the menu and the reason is in the checks.

Making a PDF is the one time a file leaves your browser: the static redline is sent to the redline server to be converted, and deleted there straight afterwards.
