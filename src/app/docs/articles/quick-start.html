1. Open redline

    Press get started on the home page, or open redline from the top of these docs.

  2. Add the original

    Drop the earlier version into the original box, or click the box to choose a file. Word documents (.docx) only, up to 25 MB.

  3. Add the modified version

    Do the same with the later version in the modified box.

  4. Create the redline

    Press create redline. The comparison runs in your browser and takes a few seconds.

  5. Read it

    Use the arrows at the top to jump from change to change. Switch between continuous and pages, or between a dark and a light page.

  6. Download it

    Press download pdf, or choose a Word format from the arrow next to it. Each file is checked before it is offered.

If either document already contains tracked changes, redline compares them as if every change had been accepted, and says so above the redline.
