Why I built it

I built redline for my own legal work and for friends who need the same thing: a clean, Litera-style redline, without a licence fee and without sending anyone's document to a server.

What it does

  • Compares an original and a modified Word document (.docx).
  • Marks text that was inserted, deleted or moved, and counts formatting changes.
  • Lets you read the redline as one continuous page or as Word-style pages, on a dark or light page.
  • Downloads it as a PDF, a Word file with the changes marked up, or a Word file with tracked changes.
  • Checks every file against your two documents before offering it.

What it does not do

  • It does not upload your documents. The one exception is making a PDF, covered in privacy.
  • It does not use AI. The same two documents always give the same redline.
  • It does not need an account, and it keeps nothing.
